Two properties, both tested

01

The model never sees a PAN

A Luhn + issuer-prefix detector replaces the number with [[CARD_n]] before the prompt exists. Tools resolve the token to brand and last four only.

02

The model cannot authorize money

The model can request a refund. A deterministic policy checks ownership, refundable balance, and the auto-approval cap, then mints a single-use token the model never sees.

03

A guard miss is still safe

The injection heuristic is intentionally imperfect. The policy-override scenario bypasses it and still cannot move money. That is the defense-in-depth point.
